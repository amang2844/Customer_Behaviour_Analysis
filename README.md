# Customer Shopping Behavior Analysis
End-to-end data analytics project analyzing customer shopping behavior
using Python, SQL, and an interactive Power BI dashboard.
## What I did
- Cleaned and explored the customer shopping dataset using Python
 (Pandas, Matplotlib, Seaborn) — handled missing values, standardized
 columns, and ran univariate/bivariate EDA
- Wrote SQL queries (aggregations, joins, and filtering) to surface
 revenue trends, top customer segments, and shipping preferences
- Built an interactive Power BI dashboard tracking revenue, customer
 segmentation, and shipping-method impact on order value
- Evaluated how discounts, subscriptions, and shipping method choice
 affected average order value and customer retention
## Tech stack
Python (Pandas, NumPy, Matplotlib, Seaborn) · SQL · Power BI · Jupyter Notebook
## Files in this repo
- `EDA.ipynb` — data cleaning and exploratory analysis
- `SQLQuery1.sql` — SQL queries used for aggregation and analysis
- `Final_Dashboard.pbix` — the Power BI dashboard file
- `Customer Shopping Behavior Analysis.pdf` — summary report
